Qué esWhat it is

Las herramientas para escritores separan tres cosas que en la práctica van juntas: aprender el oficio, construir el mundo y escribir el libro. Writers las une en una sola app de escritorio.

La Escuela tiene lecciones de oficio cuyos ejercicios crean o enriquecen fichas reales del libro. Esas fichas (personajes, lugares, facciones, sistemas de magia…) viven en un lienzo infinito y alimentan vistas derivadas: cronología con calendarios inventados, grafo de relaciones, hilos de trama y estructuras. El Manuscrito se escribe por escenas, con menciones a las fichas y un corrector que aprende los nombres de tu mundo.

La IA está planteada como un editor: revisa continuidad, detecta huecos y hace preguntas, pero no escribe la prosa. El contexto que se le envía es visible y editable antes de cada petición, y se muestra el coste real de cada respuesta.

Writing tools tend to separate three things that in practice go together: learning the craft, building the world and writing the book. Writers brings them together in a single desktop app.

The School has craft lessons whose exercises create or enrich real entities of the book. Those entities (characters, places, factions, magic systems…) live on an infinite canvas and feed derived views: a timeline with invented calendars, a relationship graph, plot threads and story structures. The Manuscript is written scene by scene, with mentions of entities and a spell checker that learns your world's names.

AI is designed as an editor: it checks continuity, spots gaps and asks questions, but it doesn't write the prose. The context sent to it is visible and editable before each request, and the real cost of every answer is shown.

ArquitecturaArchitecture

La app es local-first. La interfaz en React y el núcleo en TypeScript puro corren dentro del webview de Tauri, y el núcleo no sabe en qué plataforma está: pide disco o IA a una capa de plataforma, que en escritorio delega en el proceso nativo en Rust.

Ese proceso nativo es la única salida al exterior: lee y escribe la carpeta del proyecto y los ajustes de la app, consulta el llavero del sistema y hace las peticiones a los proveedores de IA (Claude, OpenAI u Ollama en local). El índice SQLite con búsqueda de texto completo vive en memoria y se reconstruye a partir de los archivos.

The app is local-first. The React UI and the pure-TypeScript core run inside Tauri's webview, and the core doesn't know which platform it runs on: it asks a platform layer for disk or AI access, which on desktop delegates to the native Rust process.

That native process is the only way out: it reads and writes the project folder and the app settings, uses the OS keychain and makes the requests to AI providers (Claude, OpenAI or local Ollama). The SQLite full-text index lives in memory and is rebuilt from the files.

Decisiones técnicasTechnical decisions

  • Archivos como fuente de verdad. Todo se guarda en Markdown con YAML y JSON Canvas legibles y versionables con git. La base SQLite + FTS5 (en WebAssembly) es solo un índice derivado que se puede reconstruir en cualquier momento.Files as the source of truth. Everything is stored as readable, git-friendly Markdown with YAML and JSON Canvas. The SQLite + FTS5 database (in WebAssembly) is only a derived index that can be rebuilt at any time.
  • Tauri en lugar de Electron. Instalador de 3–15 MB y menos memoria. La lógica vive en TypeScript y Rust queda solo para lo nativo. Un test impide que el núcleo importe React o Tauri.Tauri instead of Electron. A 3–15 MB installer and lower memory use. Logic lives in TypeScript; Rust is kept for native concerns only. A test prevents the core from importing React or Tauri.
  • IA segura por diseño. Las claves de API se guardan en el llavero del sistema, no en la interfaz, y la red solo se usa desde el proceso nativo para hablar con los proveedores de IA.Secure-by-design AI. API keys are kept in the OS keychain, not in the UI, and the network is only used from the native process to talk to AI providers.
  • IA transparente. El contexto que se envía se ve como chips editables, la «biblia» del libro se cachea con prompt caching y cada respuesta muestra su coste real. Hay alternativa local con Ollama.Transparent AI. The context being sent is shown as editable chips, the book's “bible” is cached with prompt caching and every answer shows its real cost. A local alternative with Ollama is available.
  • Privacidad y trabajo offline. Corrector ortográfico local, fuentes servidas sin CDN y eliminación de metadatos (EXIF/GPS) en las imágenes que se suben.Privacy and offline work. Local spell checker, fonts served without a CDN and metadata (EXIF/GPS) stripped from uploaded images.
